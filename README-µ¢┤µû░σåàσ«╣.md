# かびるんるんブラウザ（Netlify版）更新内容

## カビパン育成：キャラクター所持・合成機能

- キャラクター所持上限を200体から1,000体に変更。
- ガチャは所持上限を超える場合に引けないように変更。
- 同じ通常キャラクターを100体消費して、強化版を1体獲得できる「100体合成」を追加。
- 強化版はガチャから排出されず、通常版の効果を基本2倍にした性能。
- 「1体捨てる」機能を追加。
- 編成中またはトレード出品中のキャラクターは、合成素材・廃棄対象にしない。
- 合成・廃棄はサーバー側で認証・所持数確認をしてから保存。
- Netlify Functions の `/api/game` を更新しているため、`index.html` だけでなく `netlify/functions/game.js` も一緒にデプロイすること。

## デプロイ

このZIPの内容を既存のNetlifyプロジェクトへアップロード／デプロイしてください。既存サイトのデータを消去する操作は不要です。念のため、デプロイ前にNetlify Blobsのデータをバックアップしてください。

## 動作確認項目

1. 1回・10連ガチャで1,000体を超えないこと。
2. 同じキャラを100体所持した状態で合成すると、100体が消費され強化版1体が増えること。
3. 99体以下では合成できないこと。
4. 1体捨てると所持数が1減ること。
5. 編成中・トレード出品中のキャラは合成・廃棄できないこと。
6. 再読み込み後も所持数と強化版が維持されること。

※この更新では既存の画面・ガチャ確率・育成データ形式をできるだけ維持しています。実際のNetlify環境でのデプロイ後テストは別途必要です。
